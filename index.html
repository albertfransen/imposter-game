🎭 How to Play

Game Overview

Imposter is a social deduction game where players try to find the imposter(s) among them!

Setup

  1. Choose a category (or use custom words)
  2. Set the number of players (3-20)
  3. Set the number of imposters (1-5)
  4. Optional: Set a game timer

How to Play

  1. Pass the device to each player
  2. Each player clicks to see their role
  3. Regular players see a secret word
  4. Imposters see "IMPOSTER"
  5. Players take turns describing the word without saying it
  6. Imposters try to blend in without knowing the word
  7. After discussion, vote on who you think the imposter is!

Winning

  • Regular Players Win: If they correctly identify all imposters
  • Imposters Win: If they avoid detection or regular players vote wrong
